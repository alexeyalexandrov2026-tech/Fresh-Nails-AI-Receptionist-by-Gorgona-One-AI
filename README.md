# Fresh Nails AI Receptionist

**Fresh Nails AI Receptionist** — это независимый проект виртуального администратора для салона красоты премиум-класса. Проект работает как отдельный микросервис (в собственном репозитории) и взаимодействует с основным сайтом через API.

## 🏗 Архитектура (Интеграция мощных движков)
Проект не "изобретает велосипед", а объединяет лучшие Enterprise и Open-Source решения в единую, мощную экосистему:

1. **Next.js (React, Tailwind, shadcn/ui)** — Премиальный пользовательский интерфейс чата и панель администратора.
2. **Dify (AI Engine)** — Мозг системы, база знаний (RAG) и оркестратор промптов (LLM OpenAI / Anthropic).
3. **Cal.com (Booking Engine)** — Индустриальный стандарт управления расписанием, мастерами и рабочими часами. Используется через API.
4. **n8n (Automation Engine)** — Асинхронный воркер для связывания систем через Webhooks (Отправка SMS через Twilio, Email, интеграция со Stripe).
5. **Supabase (PostgreSQL)** — Единый источник правды. Наша центральная CRM для хранения профилей клиентов, истории визитов и логов общения ИИ.
